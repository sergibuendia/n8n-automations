# Scraper masivo - 📧📈💻 Generador de correos electrónicos y envio masivo de correos a empresas con propuestas de negocio personalizadas 🤖🧠🌐

Este flujo en n8n permite automatizar el proceso completo de generación, validación y envío de correos electrónicos personalizados a empresas:

## 🔧 Funcionalidades principales:

- ✅ Lectura automática de nuevas filas desde Google Sheets (datos de empresas y contactos).
- 🧠 Generación dinámica de correos personalizados mediante plantilla HTML (con nombre del contacto y valores de la empresa).
- 🧹 Validación masiva de emails usando la API de Bouncer (o alternativa como EmailListVerify).
- 🔁 Separación y gestión de correos válidos y no válidos.
- 📤 Envío automatizado de correos personalizados a direcciones válidas.
- 📊 Registro de resultados en distintas hojas de Google Sheets.
- 📎 Integración con otros sistemas (CRM, AI, etc).

## 💡 Casos de uso:
Ideal para campañas de contacto B2B, generación de leads o procesos de adquisición empresarial.
